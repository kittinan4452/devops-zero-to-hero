Subnetting คือเรื่องที่คนกลัวที่สุดในเน็ตเวิร์ก แต่จริงๆ มันคือ "การแบ่งบ้านเลขที่" — เข้าใจครั้งเดียวใช้ได้ตลอด

---

## 1. Subnet Mask คืออะไร

IP address แบ่งเป็น 2 ส่วน: **Network** (บ้านไหน) + **Host** (คนไหนในบ้าน)
Subnet mask บอกว่าแบ่งตรงไหน

```
IP:    192.168.1.10
Mask:  255.255.255.0   →  /24
       └─ Network ─┘└Host┘
```

---

## 2. CIDR Notation (/24 คืออะไร)

`/24` = มี **24 บิตแรก** เป็น network ที่เหลือเป็น host

| CIDR | Mask | จำนวน host ใช้ได้ |
|---|---|---|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |
| /30 | 255.255.255.252 | 2 |

:::note[สูตรจำนวน host]
```
host ที่ใช้ได้ = 2^(32 - CIDR) - 2
```
ลบ 2 เพราะ **network address** (ตัวแรก) และ **broadcast** (ตัวสุดท้าย) ใช้เป็น host ไม่ได้
:::

---

## 3. คำนวณ subnet — ตัวอย่างจริง

โจทย์: `192.168.1.0/26` มีอะไรบ้าง?

```
/26 → block size = 256 - 192 = 64
แต่ละ subnet มี 64 addresses
```

| Subnet | Network | Host range ใช้ได้ | Broadcast |
|---|---|---|---|
| 1 | 192.168.1.0 | .1 – .62 | 192.168.1.63 |
| 2 | 192.168.1.64 | .65 – .126 | 192.168.1.127 |
| 3 | 192.168.1.128 | .129 – .190 | 192.168.1.191 |
| 4 | 192.168.1.192 | .193 – .254 | 192.168.1.255 |

**วิธีคิดเร็ว:**
1. block size = 256 − ค่า mask ของ octet สุดท้าย (256−192 = 64)
2. network address ไล่ทีละ block (0, 64, 128, 192)
3. broadcast = network ถัดไป − 1
4. host = ระหว่าง network+1 ถึง broadcast−1

---

## 4. VLSM — แบ่ง subnet ขนาดไม่เท่ากัน

โลกจริงแต่ละแผนกใช้ host ไม่เท่ากัน — VLSM (Variable Length Subnet Mask) แบ่งตามความต้องการจริง

**หลักการ:** เริ่มจากแผนกที่ต้องการ host **มากสุดก่อน** แล้วไล่ลง

ตัวอย่าง จาก `192.168.1.0/24`:
| แผนก | ต้องการ host | เลือก CIDR | ได้ range |
|---|---|---|---|
| Sales (100) | 100 | /25 (126) | .0 – .127 |
| IT (50) | 50 | /26 (62) | .128 – .191 |
| HR (20) | 20 | /27 (30) | .192 – .223 |

ประหยัด IP กว่าการให้ทุกแผนก /24 เท่ากัน

## 5. Private IP ranges (ทบทวน)

| Class | ช่วง | CIDR |
|---|---|---|
| A | 10.0.0.0 – 10.255.255.255 | /8 |
| B | 172.16.0.0 – 172.31.255.255 | /12 |
| C | 192.168.0.0 – 192.168.255.255 | /16 |

## สรุป

| แนวคิด | จำ |
|---|---|
| CIDR | จำนวนบิต network (/24 = 24 บิต) |
| host = 2^(32−CIDR) − 2 | ลบ network + broadcast |
| block size | 256 − mask octet |
| VLSM | แบ่งตามความต้องการจริง (มากไปน้อย) |
