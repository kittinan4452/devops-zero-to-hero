## ติดตั้ง

<Tabs>
<TabItem label="macOS">

**วิธีที่ 1 — Homebrew (แนะนำ)**
```bash
brew install --cask docker
```
เปิดแอป Docker จาก Applications ครั้งแรกเพื่อให้มัน setup

**วิธีที่ 2 — โหลดไฟล์เอง**
1. โหลด `.dmg` จาก https://www.docker.com/products/docker-desktop/
2. เลือกให้ถูกชิป: **Apple Silicon** (M1/M2/M3) หรือ **Intel**
3. ลากเข้า Applications แล้วเปิด

</TabItem>
<TabItem label="Windows">

**เตรียม WSL2 ก่อน** (backend ที่แนะนำ)
```powershell
wsl --install
# restart เครื่องหลังติดตั้งเสร็จ
```

**ติดตั้ง Docker Desktop**
```powershell
winget install Docker.DockerDesktop
```
หรือโหลด installer จาก https://www.docker.com/products/docker-desktop/ แล้วติดตั้ง (เลือก **Use WSL 2 instead of Hyper-V**)

</TabItem>
</Tabs>

## ตรวจสอบว่าใช้งานได้

```bash
docker --version
docker run --rm hello-world
docker compose version
```

ถ้าเห็นข้อความ "Hello from Docker!" = พร้อมใช้งาน

## ตั้งค่าทรัพยากร (ถ้าเครื่องช้า/หน่วง)

เปิดแอป → **Settings → Resources** ปรับ CPU / Memory / Disk ตามเครื่อง
(แนะนำอย่างน้อย CPU 2, RAM 4GB สำหรับงานทั่วไป)

## เปิด Kubernetes (ถ้าต้องใช้)

**Settings → Kubernetes → Enable Kubernetes** → Apply — จะได้ single-node cluster ใช้กับ `kubectl` ได้เลย
